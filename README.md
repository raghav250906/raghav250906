## Featured Projects

### 🔍 Code Plagiarism Detector
> Java · Spring Boot · HTML · CSS

A full-stack plagiarism detection system that compares source code snippets and returns quantified similarity scores using tokenization algorithms. Built RESTful APIs for code submission, processing, and result retrieval — designed for concurrent request handling — and a web interface for side-by-side visualization that reduces manual review time for educators.

---

### 🏟️ Stadium AI — Smart Event Assistant
> HTML · CSS · JavaScript

An AI-powered event assistant built for large sporting venues. Provides real-time attendee support for navigation, schedules, and FAQs via a conversational UI. Built and submitted during the **Hack2Skill Virtual Prompt War Challenge** — addressed real-world event logistics and crowd management under competition constraints.

---

### 🗳️ AI Election Assistant
> HTML · CSS · JavaScript

A civic-tech AI assistant that simplifies election information and ballot guidance for first-time voters through natural-language Q&A. Built with an emphasis on accessibility and intuitive UX as part of an innovation challenge.

---

### 🚦 Traffic Flow Analysis & Prediction
> Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn

An end-to-end machine learning system for traffic analysis and prediction. Covers data preprocessing, feature engineering, EDA, and forecasting of congestion patterns using historical datasets — from raw data to actionable insights.
