## Featured Projects

### 🔐 OfflinePay Mesh — Secure Offline Payment Routing & Settlement
**Tech:** Java · Spring Boot · H2 · JPA · RSA-OAEP · AES-256-GCM

A Spring Boot system demonstrating secure offline payment routing through a simulated Bluetooth-style mesh network with deferred settlement. Implements hybrid RSA-OAEP + AES-256-GCM encryption so payment data stays protected even when passing through untrusted intermediary devices, and detects tampering in transit. Settlement is handled with exactly-once guarantees — SHA-256 ciphertext hashing, atomic idempotency checks, and replay protection against duplicate or concurrent deliveries.

### 🔍 Code Plagiarism Detector
**Tech:** Java · Spring Boot · HTML · CSS

A full-stack plagiarism detection system that tokenizes submitted source code and computes similarity scores between submissions. Includes a web interface for side-by-side comparison with a visual similarity breakdown.
